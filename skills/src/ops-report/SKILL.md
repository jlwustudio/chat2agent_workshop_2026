# 禾川精密營運報告格式

## 什麼時候用
使用者提供廠區或部門的週會紀錄、員工與客戶回饋、營運數字（貼上文字或上傳檔案），要求產出週報或月報時。

## 產出步驟
1. 先讀完所有提供的資料，不要只讀前幾份。
2. 把問題分類，固定用這五類：交期、品質、人力、設備、安全與永續；不屬於這五類的放「其他」。
3. 每一類算出：提到的次數、涉及哪些廠區／部門、一句話描述。
4. 數字有衝突時（例如兩份資料寫的出貨量不同），**不要自己挑一個**，在「待確認事項」列出兩個數字和出處。
5. 產出 Word 檔（.docx），結構如下。

## 報告結構
```
禾川精密｜{週報/月報}｜{期間}

一、本期重點（3 點，每點一句話，主管 30 秒看完）
二、問題分類統計（表格：類別｜次數｜涉及廠區／部門｜說明）
三、需要主管決定的事（每項附：選項、建議、理由）
四、待確認事項（資料衝突、資訊不足）
五、資料來源（列出讀過的檔名）
```

## 寫作規則
- 繁體中文、台灣用語；句子短，一句只講一件事。
- 不寫空泛的話（例如「持續精進品質」），每一點都要有具體廠區、數字或行動。
- 所有數字都要能對回原始資料；沒有出處的數字不能寫。
- 篇幅：週報 1 頁、月報不超過 2 頁。
