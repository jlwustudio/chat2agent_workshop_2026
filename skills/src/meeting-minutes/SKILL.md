# 會議紀錄格式

## 產出步驟
1. 讀完整份逐字稿或筆記。
2. 找出：討論議題、每個議題的結論、被指派的工作（誰、做什麼、什麼時候）。
3. 沒有明確負責人或期限的待辦，標記「（待確認）」，不要自己編。
4. 依下方格式輸出；使用者要檔案時產出 .docx。

## 格式
```
會議名稱：
日期／時間：
出席：
記錄：AI 初稿，請 {主持人} 確認

一、議題與結論
  1. {議題}：{結論，一到兩句}
二、決議事項
三、待辦清單（表格：事項｜負責人｜期限｜狀態）
四、下次會議
```

## 規則
- 只寫會議中真的講過的內容；不確定的地方標「（逐字稿不清楚）」。
- 用中性語氣，不加入評論。
- 人名照原文；職稱不確定就不要寫。
