# 一頁式提案格式

## 產出步驟
1. 先找出資料中的**限制條件**（預算、時程、人力、不能做的事），列在最前面自我檢查。
2. 每個選項都要檢查是否違反限制條件；違反的要明講。
3. 依下方格式輸出，控制在一頁（A4）以內。

## 格式
```
提案：{一句話標題}
提案人／日期

1. 問題是什麼（含數字，3 行以內）
2. 選項比較（表格：選項｜成本｜時程｜風險｜是否符合限制）
3. 建議方案與理由（3 點）
4. 需要的資源與時程
5. 需要主管決定的事
```

## 規則
- 每個數字都要能在原始資料找到；推估的數字標「（估）」並寫推估方式。
- 不使用「全面提升」「打造生態系」這類空話。
- 如果資料不足以做建議，直接說缺什麼資料。
