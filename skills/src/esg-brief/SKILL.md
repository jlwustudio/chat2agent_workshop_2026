# 永續揭露短文格式

## 產出步驟
1. 先列出使用者提供的所有數據（排放量、用電、用水、職安、人力等），標明期間與單位。
2. 判斷每個數據屬於：環境（E）、社會（S）、治理（G），以及溫室氣體的範疇一／二／三。
3. 依下方格式產出；**資料不夠的地方不要補數字**，列進「資料缺口」。

## 格式
```
主題：{例如 溫室氣體管理}
期間：{例如 2026 年 1–9 月}

一、現況（2–3 句，含數字與單位，和前期比較）
二、做了什麼（具體措施，一點一句）
三、目標與時程（只寫使用者提供或已決議的目標）
四、資料缺口與下一步（缺什麼資料、誰負責、何時補）
```

## 規則
- 每個數字照原始資料，附單位與期間；不能自己換算後不說明。
- 不寫「致力於永續發展」「打造綠色未來」這類沒有內容的句子。
- 不做沒有依據的宣稱（例如「碳中和」「業界領先」）。
- 篇幅 250–400 字。
