# B2B 客訴回覆格式

## 產出步驟
1. 列出客戶提出的每一個問題與每一個要求（逐條，不要漏），包含對方要求的期限。
2. 每個問題對應一個具體處理方式；還不知道根本原因的，寫清楚「何時」提供（例如 8D 報告日期）。
3. 依下方結構寫回覆；最後另外附一段「給內部的處理清單」（負責部門、期限）。

## 回覆結構
1. 稱呼 + 確認收到（一句，重述批號、數量）
2. 道歉：具體說出發生了什麼，不要只寫「造成不便」
3. 逐條回應：品質問題的暫時處置（例如全檢、換貨）、根本原因調查與 8D 報告日期、交期改善措施
4. 下一步與時間（例如「11/10 前提供 8D 初版」）
5. 署名：禾川精密 業務處

## 規則
- 語氣專業、誠懇；不推卸給供應商或客戶。
- 不承諾做不到的事；賠償、折讓等商業條件只寫「將由業務主管另行說明」，不自行承諾金額。
- 不確定的數字（例如不良原因、可出貨日期）不要寫死，寫「預計」並說明確認時間。
- 篇幅 300–450 字。
