今天會做什麼

L1
對話：問問題、拿答案。大部分人停在這裡。
L2
給它資料與規則：Project + Skill，打造你自己的工作助理，直接產出 Word / Excel。你動手・免費
L3
交辦任務：深度研究、排程任務，讓它自己做完再交給你驗收。老師示範・Pro
L4
打造 Agent 團隊：Claude Code + Subagents，一個人變一個小組。老師示範・Pro

每一段都會你用免費版做、老師用 Pro 做同一題，兩邊結果並排投影。你會親眼看到升級差在哪裡，回去自己判斷值不值得。

怎麼上這堂課

  • 每個人用自己的電腦動手做。卡住就舉手，或直接問旁邊的同學。
  • 不會寫程式完全沒關係：主線全部用點的、用打字的。會寫程式的人有「程式組加碼」。
  • 免費版有用量上限（每 5 小時一個額度）。講義每個實作都標了預估用量；用完了就和鄰座一起看一台。
⚠️ 今天用的都是虛構資料

「禾川精密」是為課程編的公司。請不要把你公司的機密、客戶個資、未公開的財報上傳到免費版 AI。回去要用在工作上，先問公司的資訊安全規定。
