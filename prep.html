💡 用網頁版就好，不用安裝

你今天用瀏覽器開 claude.ai（網頁版）。不用安裝任何軟體，公司電腦沒有安裝權限也能用。

已經裝了 Claude 桌面版的人也可以用桌面版。登入同一個帳號，Project、Skill 和對話都會同步，兩邊的操作一樣。桌面版裡的 Code 分頁就是 Claude Code，要 Pro 才能用，今天由老師示範。

1. 註冊 Claude 免費帳號

1

打開 claude.ai

前往 claude.ai，用 Google 帳號或 Email 註冊。手機驗證碼收到後輸入即可。

2

確認登入成功

看到對話輸入框就成功了。左下角顯示的方案是 Free 沒關係——今天你動手的部分全部用免費版。

👀 輸入「你好，請用一句話介紹你自己」送出，有回覆就 OK。

2. 打開檔案功能

實作②要讓 Claude 產出 Word 檔、使用 Skill，需要先確認這兩個開關是打開的：

3

設定 → 功能（Capabilities）

點左下角你的名字 → Settings → Capabilities，確認以下兩項是開啟的：

  • Artifacts：讓 Claude 在對話旁邊的視窗打開文件（下一項需要它）
  • Create and edit files：讓 Claude 產出可下載的 Word、Excel、簡報、PDF。Skill 也需要這項開著
💡 其他開關不用動

Skill 的上傳位置在左側選單 Customize → Skills（實作②會用到），不在 Settings。

「Use the internet while making files」、Claude in Chrome、Connectors 今天都用不到，維持預設就好。介面是中文的話，名稱會是對應的中文。

3. 自檢清單

0 / 4 項完成

勾選進度會記在這個瀏覽器裡，關掉頁面再回來還在。

常見問題

要用網頁版還是桌面版？

網頁版就好。桌面版功能一樣、帳號同步，已經裝了的人用桌面版也可以。今天不需要安裝 Claude Code。

一定要付費嗎？

不用。你動手的部分全部用免費版。需要 Pro 的功能（深度研究、排程、桌面版的 Claude Code）由老師現場示範，你看得到兩邊差多少。

上課中額度用完了怎麼辦？

免費版每 5 小時有用量上限。用完了就和鄰座併桌看同一台，或改看老師的示範。講義每個實作都有標預估用量。

可以用公司的資料練習嗎？

今天請用課程提供的虛構資料。回去要用公司資料前，先確認公司的資訊安全規定；企業通常會用有資料保護條款的 Team / Enterprise 方案。
